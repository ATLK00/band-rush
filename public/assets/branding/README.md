# โลโก้เกม

ไฟล์นี้ (`logo.png`) คือโลโก้ที่ใช้แทนคำว่า **"จับคู่เครื่องดนตรี"** ทุกจุดในเกม —
หน้ารอเชื่อมต่อ (loading) และหัวมุมซ้ายบนของทั้งหน้าผู้เล่นกับหน้าหัวห้อง

## วิธีใช้

เอารูปโลโก้ของคุณมาทับไฟล์ `logo.png` ในโฟลเดอร์นี้ (**ชื่อไฟล์ต้องเหมือนเดิมเป๊ะ**) แล้วรีเฟรชหน้าเว็บ
ไม่ต้องแก้โค้ดใดๆ

## ข้อกำหนดไฟล์ (แนะนำ)

- ฟอร์แมต `.png` พื้นหลังโปร่งใส (transparent) จะดูดีที่สุด เพราะพื้นหลังเกมเป็นสีเข้ม
- สัดส่วนแนวนอน (กว้างกว่าสูง) ประมาณ 2.5–3 : 1 เช่น 480×180 พิกเซล ใกล้เคียงกับไฟล์ตัวอย่าง
- ไม่จำเป็นต้องละเอียดมาก เพราะพื้นที่แสดงจริงเล็ก (สูงราว 40–90px แล้วแต่จุด)

ถ้าลบไฟล์นี้ทิ้งหรือไฟล์เสีย เกมจะ fallback กลับไปแสดงคำว่า "จับคู่เครื่องดนตรี" เป็นตัวอักษรแทนอัตโนมัติ
ไม่มีอะไรพัง
