# รูปเครื่องดนตรี

โฟลเดอร์นี้เก็บรูปที่การ์ดในเกมใช้แสดงตอนพลิกไพ่ "ชื่อเครื่องดนตรี" (ไพ่ประเภท "หมวดหมู่"
ยังใช้ไอคอนเส้นแบบเดิมอยู่ ไม่เกี่ยวกับโฟลเดอร์นี้)

## กติกาการตั้งชื่อไฟล์

**ชื่อไฟล์ต้องตรงกับ `id` ของเครื่องดนตรีใน `server.js` เป๊ะๆ** (ตัวพิมพ์เล็กทั้งหมด, ไม่มีเว้นวรรค)

ตอนนี้เกมรู้จักเครื่องดนตรี 14 ชิ้นนี้ (ดูรายการเต็มได้ที่ตัวแปร `INSTRUMENTS` ใน `server.js`):

| ไฟล์ที่ต้องใช้ | เครื่องดนตรี |
|---|---|
| `drum_kit.png` | กลองชุด |
| `maracas.png` | มาราคัส |
| `xylophone.png` | ระนาดเอก |
| `cymbal.png` | ฉาบ |
| `guitar.png` | กีตาร์ |
| `violin.png` | ไวโอลิน |
| `harp.png` | ฮาร์ป |
| `cello.png` | เชลโล |
| `trumpet.png` | ทรัมเป็ต |
| `trombone.png` | ทรอมโบน |
| `saxophone.png` | แซกโซโฟน |
| `flute.png` | ขลุ่ย |
| `piano.png` | เปียโน |
| `accordion.png` | หีบเพลง |

ตอนนี้ทุกไฟล์เป็นรูป **placeholder ตัวโน้ตดนตรีเหมือนกันหมด** — แทนที่ไฟล์ไหนก็ได้ด้วยรูปจริงของคุณ
โดยตั้งชื่อไฟล์ให้ตรงกับตารางด้านบน แล้วรีเฟรชหน้าเว็บ ไม่ต้องแก้โค้ดอะไรเลย

## อยากเพิ่มเครื่องดนตรีใหม่ (ไม่ใช่แค่เปลี่ยนรูป)

1. เปิด `server.js` หาตัวแปร `INSTRUMENTS` (มีคอมเมนต์อธิบายไว้ด้านบนแล้ว)
2. เพิ่มบรรทัดใหม่ เช่น
   ```js
   { id: "ukulele", th: "อูคูเลเล่", category: "strings" },
   ```
   - `id` ต้องไม่ซ้ำใคร, ตัวพิมพ์เล็ก, ไม่มีเว้นวรรค — ใช้ชื่อนี้ตั้งไฟล์รูปด้วย (`ukulele.png`)
   - `category` ต้องเป็นหนึ่งใน 5 หมวดที่มีอยู่แล้ว: `percussion`, `strings`, `brass`, `woodwind`, `keyboard`
3. เอารูป `ukulele.png` มาวางในโฟลเดอร์นี้ (หรือปล่อยไว้ก่อนก็ได้ — เกมจะโชว์รูป placeholder
   ตัวโน้ตดนตรีแทนอัตโนมัติ ไม่มีอะไรพังตาย)
4. เสร็จแล้ว — **ไม่ต้องแก้ไฟล์อื่นเลย** ทั้ง client.js และ host.js อ่านชื่อ/หมวดหมู่ของ
   เครื่องดนตรีจาก server ตรงๆ ไม่มีลิสต์ซ้ำที่ต้องคอยแก้ตาม

## ข้อกำหนดไฟล์รูป (แนะนำ)

- ฟอร์แมต: `.png` (มี transparent background จะสวยที่สุด เพราะการ์ดพื้นขาว)
- สัดส่วนสี่เหลี่ยมจัตุรัส (เช่น 512×512) เพราะพื้นที่แสดงบนการ์ดเป็นสี่เหลี่ยมจัตุรัส
- ไม่ต้องเซ็ตความละเอียดสูงมาก — การ์ดแสดงผลจริงแค่ ~130px กว้าง

ถ้าไฟล์รูปหาย/พังหรือชื่อผิด เกมจะ fallback ไปโชว์ `_placeholder.png` ให้อัตโนมัติ
(อย่าลบไฟล์นี้ทิ้ง มันคือ fallback กลางที่ใช้ตอนหาไฟล์เฉพาะเจาะจงไม่เจอ)
